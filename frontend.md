# Frontend UI/UX Rules

## Skill Orchestration

For every frontend UI/UX task, read this file.

Select relevant installed skills:

- design-taste-frontend:
  Premium aesthetics and anti-AI design.

- frontend-design:
  Original compositions and visual identity.

- design:
  General design reasoning.

- design-system:
  Design tokens and visual consistency.

- ui-styling:
  Typography, color, spacing and polish.

- ui-ux-pro-max:
  UX patterns, accessibility and usability.

Do not activate every skill blindly.
Follow project rules when skills conflict.

## Design Principles

- Avoid generic AI-generated aesthetics.
- Avoid unnecessary gradients and glassmorphism.
- Avoid excessive cards, shadows and radii.
- Prefer intentional, original compositions.
- Use Outfit as the primary font.
- Minimum text size: 1rem.
- Mobile-first responsive design.
- Clear-space layout and readable hierarchy.
- Support Turkish and long translated text.
- Accessible contrast and keyboard navigation.

## Implementation Quality

- Reuse existing components and design tokens.
- Preserve functionality and business logic.
- Avoid unnecessary dependencies.
- Validate mobile, tablet and desktop layouts.
- Inspect rendered UI when browser tools exist.
- Fix visual defects before completing the task.
